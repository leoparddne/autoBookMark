# 课程收藏夹进度追踪（Edge 浏览器扩展）

一个 Edge / Chrome 浏览器扩展，用于**为在线课程自动更新收藏夹进度**：当你学完一集、切换到下一集时，收藏夹里对应的那条收藏会自动替换成最新一集的标题和网址，位置保持不变。

## 解决的问题

在线课程（如 B 站、各类网课平台）通常一个课程链接下有很多集。如果每集都收藏，收藏夹会堆满几十条；如果只收藏一次，又容易丢失"学到哪一集"的进度。

本扩展让你**只需一条收藏**，它会自动跟随你的学习进度滚动更新，始终指向你最新看到的那一集。

## 核心特性

| 特性 | 说明 |
|---|---|
| 自动更新 | 打开/切换到课程的新一集后，自动更新收藏夹（约延迟 1.2 秒，等页面标题就绪） |
| 原地替换 | 更新的是同一条收藏，**位置、所属文件夹、排序都不变** |
| 首次自动创建 | 该课程还没有收藏时，自动在「其他书签」里新建一条 |
| 多课程隔离 | 通过正则捕获组区分不同课程/视频，更新 A 课程不会影响 B 课程 |
| SPA 兼容 | 支持 B 站这类单页应用（切集时 URL 变化但不刷新页面） |
| 手动兜底 | 弹窗内可手动"立即更新本页收藏"，应对特殊页面 |
| 规则可配置 | 在设置页自由增删站点规则，支持任意网站 |

## 工作原理

```
访问课程页面
   │
   ▼
页面加载完成 / URL 变化（含 SPA 切集）
   │
   ▼
匹配站点规则（域名 + URL 正则）
   │
   ▼
计算"课程标识"（正则第一个捕获组，如 B 站 BV 号）
   │
   ├── 收藏夹中已存在同一课程 → 更新它（位置不变）
   │
   └── 不存在 → 在「其他书签」新建一条
```

关键点：**"是不是同一个课程"由正则的第一个捕获组决定**（例如 B 站的 BV 号）。集数参数（如 `p=17`）只参与匹配，不参与身份判断，所以同一视频的任意一集都算同一个课程。

## 安装方法

1. 打开 Edge，地址栏输入 `edge://extensions/` 回车
2. 打开左下角（或右上角）的 **「开发人员模式」**
3. 点击 **「加载解压缩的扩展」**
4. 选择本项目根目录（包含 `manifest.json` 的那个文件夹，即 `edgebookmark`）
5. 安装成功后会自动打开设置页

> Chrome 用户同理，访问 `chrome://extensions/`。

## 使用方法

### 第一步：配置站点规则

在扩展设置页（首次安装会自动打开，也可从弹窗点「设置规则」进入）添加一条规则：

- **域名**：课程网站的主机名，如 `www.bilibili.com`
- **URL 正则**：匹配课程页面的完整 URL 的正则，用**第一个捕获组**标识"同一课程"
- **启用**：勾选

### 第二步：正常学习

1. 打开课程的任意一集
2. 扩展会自动在「其他书签」中创建一条收藏
3. 学完切到下一集，等待 1~2 秒，收藏会自动更新为下一集，**位置不变**

## 规则配置示例

### B 站

| 字段 | 值 |
|---|---|
| 域名 | `www.bilibili.com` |
| URL 正则 | `https://www\.bilibili\.com/video/(BV\w+)/?[^#]*` |

正则说明：

| 片段 | 含义 |
|---|---|
| `https://www\.bilibili\.com/video/` | 固定前缀（`.` 需转义为 `\.`） |
| `(BV\w+)` | **第一个捕获组**：视频号 `BV...`，用于区分不同视频 |
| `/?[^#]*` | 通配吸收后面的 `/`、`?p=17`、`spm_id_from=...` 等全部参数 |

效果：
- `.../BV16jyuBBEom/?...&p=17` → 视频标识 `BV16jyuBBEom`
- 切到 `p=18` → 视频标识不变 → 更新同一条收藏
- 换到别的视频 → 视频标识变化 → 互不影响

### DeepLearning.AI

示例 URL：

```
https://learn.deeplearning.ai/specializations/machine-learning/lesson/iz9z0/running-gradient-descent
```

| 字段 | 值 |
|---|---|
| 域名 | `learn.deeplearning.ai` |
| URL 正则 | `https://learn\.deeplearning\.ai/specializations/([^/]+)/lesson/.*` |

正则说明：

| 片段 | 含义 |
|---|---|
| `https://learn\.deeplearning\.ai/specializations/` | 固定前缀（`.` 需转义为 `\.`） |
| `([^/]+)` | **第一个捕获组**：课程名 `machine-learning`，用于区分不同课程 |
| `/lesson/.*` | 匹配任意 lesson 路径，`.*` 吸收 `iz9z0/running-gradient-descent` 等每节课都变化的部分 |

效果：
- 学这门课的任意一节 → 捕获组都是 `machine-learning` → 更新同一条收藏
- 换到别的 specialization（如 `/specializations/deep-learning/...`）→ 捕获组变化 → 互不影响
- 同一课程切换 lesson（ID 变化）→ 捕获组不变 → 原地替换为新课

### 通用网课（集数在路径里）

| 字段 | 值 |
|---|---|
| 域名 | `course.example.com` |
| URL 正则 | `https://course\.example\.com/course/(\d+)/.*` |

`/course/123/ep1` 与 `/course/123/ep2` 的捕获组都是 `123` → 视为同一课程。

### 只追踪单个页面（不区分课程）

正则里**不含捕获组**即可，整个规则对应唯一一条收藏：

| 字段 | 值 |
|---|---|
| 域名 | `example.com` |
| URL 正则 | `https://example\.com/lesson/.*` |

## 常见问题

**Q：切换集数后收藏夹没变化？**

- 确认已在 `edge://extensions/` 点过扩展的 **「重新加载」**（改动代码后必须重载）
- 确认当前页面命中规则：打开扩展弹窗，看提示是否为"已命中规则"
- 确认域名填写正确（注意 `www`，`bilibili.com` 和 `www.bilibili.com` 是不同主机名）
- 可先用弹窗里的「立即更新本页收藏」手动验证逻辑是否正常

**Q：收藏夹里出现多条同课程收藏？**

- 说明正则的第一个捕获组没能稳定区分课程。检查正则是否把随集数变化的参数也放进了捕获组。**第一个捕获组必须是课程/视频的稳定标识**（如 BV 号、课程 ID）。

**Q：更新后的收藏 URL 带了一堆跟踪参数（spm_id_from 等）？**

- 这是把当前页面的完整 URL 写入所致。可接受，因为下次匹配时这些参数被正则的 `[^#]*` 通配掉了，不影响识别。

**Q：为什么延迟约 1.2 秒才更新？**

- SPA 站点（如 B 站）切集时 URL 先变、页面标题后变，需要等待标题就绪才能写入正确内容。

**Q：扩展会自动创建收藏吗？会删除吗？**

- 会在课程**首次**没有收藏时自动创建一条（位于「其他书签」）。
- **不会删除**任何收藏。所谓"替换"是直接更新同一条收藏的内容，不涉及删除操作。

## 权限说明

| 权限 | 用途 |
|---|---|
| `bookmarks` | 读取、更新、创建收藏夹条目 |
| `storage` | 保存站点规则配置 |
| `tabs` | 监听标签页加载与 URL 变化 |
| `<all_urls>` | 内容脚本需注入到课程页面以监听 SPA 路由变化 |

所有数据仅保存在本地浏览器中，不涉及任何网络上传。

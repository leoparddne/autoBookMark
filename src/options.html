课程收藏夹进度追踪

用途：为在线课程持续更新收藏夹，让它始终指向你最新学习到的那一集。

规则字段：

· 域名：如 www.bilibili.com，只匹配该域名下的网页。

· URL 正则：直接填完整 URL 的正则，用「第一个捕获组」把同一课程/视频的不同集归为同一收藏项。
捕获组 1 取课程/视频的稳定标识（如视频号、课程名），用于区分不同课程；
后面随集数变化的部分用 .* 或 [^#]* 通配吸收。
同一课程的不同集 → 只更新这一条收藏；不同课程 → 互不影响。

· 启用：关闭后该规则不生效。

配置示例（可直接复制）

B 站
示例 URL：https://www.bilibili.com/video/BV16jyuBBEom/?...&p=17
域名www.bilibili.com
URL 正则https://www\.bilibili\.com/video/(BV\w+)/?[^#]*
捕获组 1 = 视频号 BV...，用于区分不同视频；/?[^#]* 通配吸收 ?p=17、spm_id_from 等参数。
同一视频切集 → 更新同一条收藏；换别的视频 → 互不影响。
DeepLearning.AI
示例 URL：https://learn.deeplearning.ai/specializations/machine-learning/lesson/iz9z0/running-gradient-descent
域名learn.deeplearning.ai
URL 正则https://learn\.deeplearning\.ai/specializations/([^/]+)/lesson/.*
捕获组 1 = 课程名 machine-learning，用于区分不同课程；/lesson/.* 吸收每节课都变化的 lesson ID 与 slug。
同一课程切换 lesson → 原地更新为新课；换别的 specialization → 互不影响。
域名 URL 正则 启用 操作
暂无规则，点击下方「新增规则」添加。
